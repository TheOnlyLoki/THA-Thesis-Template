# Fonts

This directory contains fonts required for reproducible compilation of the thesis template.

## Font Families

### Nimbus Sans (`nimbus/`)

- **Source**: https://github.com/ArtifexSoftware/urw-base35-fonts/archive/20200910/urw-base35-fonts-20200910.tar.gz
- **License**: AGPL-3.0 (see `nimbus/LICENSE` and `nimbus/COPYING`)
- **Usage**: Sans-serif font for headings and UI elements
- **Required files** (4 .otf files from fonts/ subdirectory):
  - NimbusSans-Regular.otf
  - NimbusSans-Bold.otf
  - NimbusSans-Italic.otf
  - NimbusSans-BoldItalic.otf

### TeX Gyre Termes (`texgyretermes/`)

- **Source**: https://www.gust.org.pl/projects/e-foundry/tex-gyre/termes/qtm2.004otf.zip
- **License**: GUST Font License (see license files in directory)
- **Usage**: Main serif text font (Times-compatible)
- **Required files** (4 .otf files):
  - texgyretermes-regular.otf
  - texgyretermes-bold.otf
  - texgyretermes-italic.otf
  - texgyretermes-bolditalic.otf

### TeX Gyre Termes Math (`texgyretermesmath/`)

- **Source**: https://www.gust.org.pl/projects/e-foundry/tg-math/download/texgyretermes-math-1543.zip
- **License**: GUST Font License (see license files in directory)
- **Usage**: Mathematical symbols and equations
- **Required files** (1 .otf file from opentype/ subdirectory):
  - texgyretermes-math.otf
